# Lumitech.id - Jasa Pembuatan Website & Digital Presence

Website resmi landing page dan profil bisnis untuk **Lumitech.id** — solusi pembuatan website profesional, cepat, responsif, dan siap konversi untuk UMKM, korporasi, dan brand modern.

---

## 🚀 Fitur Unggulan

- **Arsitektur Modular PHP:** Terstruktur rapi dengan pemisahan komponen `Layout/partials/app.php`, `navhome.php`, `footer.php`, dan `view/index.php`.
- **Navigasi Responsif & Mobile Menu:** Dilengkapi dengan hamburger menu drawer interaktif untuk pengalaman pengguna mobile yang mulus.
- **Showcase Portofolio & Studi Kasus:** Menampilkan 6 studi kasus hasil produksi unggulan dengan verifikasi metrik konversi dan badges teknologi.
- **Floating WhatsApp CTA Button:** Tombol aksi cepat kontak WhatsApp langsung di sudut kanan bawah dengan efek pulse.
- **Optimasi SEO & Open Graph:** Dilengkapi favicon resmi, meta description, keywords, dan Open Graph preview untuk sharing di media sosial dan WhatsApp.
- **Desain Modern:** Material Design 3 tokens dengan integrasi Tailwind CSS, typography Plus Jakarta Sans & Space Grotesk.

## 💻 Cara Menjalankan Proyek

### 1. Menggunakan Laragon (Rekomendasi)
- Pastikan folder proyek berada di direktori `C:\laragon\www\Lumitech`.
- Buka Laragon lalu klik **Start All**.
- Akses website melalui browser di: `http://localhost/Lumitech` atau `http://lumitech.test` (jika virtual host aktif).

### 2. Menggunakan PHP Built-in Server
Buka terminal PowerShell / Command Prompt di folder proyek:
```bash
php -S localhost:8000
```
Lalu buka browser di `http://localhost:8000`.
